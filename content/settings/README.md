# Website maintainer settings

These files are normally edited during setup, branding changes or deployment.

- `site.md`: public URL, default language, speciality palette, branding, colors, Analytics, metadata and optional website developer inquiry.
- `appearance/`: palette definitions. Translated palette labels are maintained in `src/lib/i18n/translations.ts`.

For patient-facing contact details, edit `doctor/contact.md`. For the doctor's actual speciality and credentials, edit `doctor/{language}/profile.md`. Appearance settings control presentation.
