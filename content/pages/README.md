# Website wording

These files control headings, introductions and instructions, grouped by language. They are not the place to update the doctor's personal details or chamber schedule: use [doctor/](../doctor/README.md).

- `en/home.md`: homepage headings and introductory wording.
- `en/profile.md`, `en/qualifications.md`: page presentation; personal details come from `doctor/en/profile.md`.
- `en/appointment.md`, `en/contact.md`: booking instructions and contact introduction.
- `en/services.md`, `en/review.md`: page wording; actual services and feedback live in `doctor/en/`.
- `en/resources/`: FAQ, help, privacy and terms.

Use the corresponding `bn` or `hi` files for translations when present. Leave `{{...}}` placeholders unchanged. They automatically insert the doctor's name, qualifications or chamber information.
